# DecisionIQ

DecisionIQ is an AI-powered Decision Intelligence Platform that helps users upload datasets, perform statistical analysis, and progressively leverage Machine Learning and AI to generate actionable insights.

---

## Vision

Build an enterprise-grade AI platform that evolves from statistical analysis to machine learning, generative AI, retrieval-augmented generation (RAG), and AI agents.

---

## Current Features (v0.1 - Foundation)

- ✅ Upload CSV files
- ✅ Dataset metadata extraction
  - Number of rows
  - Number of columns
  - Column names
  - Data types
  - Missing values
- ✅ File validation
  - Invalid file type detection
  - Empty CSV validation
- ✅ Interactive API documentation using Swagger UI
