## [v0.1] - Foundation

### Added

- Initial project structure
- FastAPI backend setup
- CSV upload endpoint
- Dataset metadata extraction
  - Row count
  - Column count
  - Column names
  - Data types
  - Missing values
- File validation
  - Invalid file type detection
  - Empty CSV validation
- Swagger UI documentation
- Initial project documentation

### Tech Stack

- Python
- FastAPI
- Pandas
- NumPy

### Notes

This release establishes the foundation for DecisionIQ by enabling users to upload datasets and inspect their structure before performing analysis.
